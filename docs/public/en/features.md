# Features

## In the app

| Feature | What it does |
|---------|--------------|
| Connect wallet | Sign in with a browser wallet. The app warns you if you are on the wrong network. |
| Create vault | Set a name, the agent wallet, a total budget, a daily limit, a per-transaction limit and a duration. |
| Fund vault | Deposit USDC into a vault. Anyone can fund any vault. |
| Pause and resume | Stop or allow an agent to spend from a vault, without moving funds. |
| Vault list | See budget used, balance, limits, expiry and status for each vault. |
| Dashboard | Total budget, total spent, available balance, active vaults, utilization and the latest spends. |
| Spend history | Every agent spend, newest first, with a link to the block explorer. |
| Settings | Network, contract address and a short integration snippet for agent developers. |

## In the contract only

These work onchain but have no screen in the app yet.

| Feature | State in the app |
|---------|------------------|
| Change limits after creation | Not available yet (TBD) |
| Allowed-destination list | Not available yet (TBD) |
| Replace the agent wallet | Not available yet (TBD) |
| Withdraw unspent balance (this also pauses the vault) | Not available yet (TBD) |
| Pause the whole contract (admin only) | Not part of the app |

You can call these functions directly from a wallet or script. See the [Agent guide](/docs/en/agent-guide) for how to find the contract.
