# Tech stack

Versions are taken from `package.json`, `.bun-version`, `.foundry-version` and `foundry.toml`.

| Layer | Technology | Version |
|-------|------------|---------|
| Runtime / package manager | Bun | 1.3.14 |
| Language | TypeScript (strict) | ~7.0.2 |
| UI | React | ^18.3.1 |
| Build / dev server | Vite (+ `@vitejs/plugin-react`, `vite-plugin-node-polyfills`) | ^6.0.5 |
| Styling | Tailwind CSS 3 + CSS variables in `src/index.css` | ^3.4.17 |
| Wallet / chain | wagmi, viem, ConnectKit | ^2.19.5, 2.57.5, ^1.9.2 |
| Data fetching | TanStack Query | ^5.62.7 |
| Icons | lucide-react, @web3icons/react | ^0.468.0, ^4.0.0 |
| Toasts | sonner | ^1.7.1 |
| Motion | framer-motion | ^11.15.0 (used by the create and fund sheets) |
| Contract | Solidity, OpenZeppelin | 0.8.28 (EVM cancun, optimizer 200 runs), 5.6.1 |
| Contract tooling | Foundry | v1.7.1 |
| Lint | oxlint (+ type-aware) | ^1.80.0 |
| Legacy backend | Bun HTTP server, `bun:sqlite` | n/a |
| Hosting | Netlify (static `dist/`) | n/a |

Chain: Arc Testnet (ID 5042002). USDC is the native gas token on Arc; the ERC-20 view has 6 decimals.

Chain facts (addresses, decimals, explorer base) come from `src/onchain-facts.ts`, which is generated by the platform. Do not edit it by hand.

Circle SDK packages are installed (`@circle-fin/*`) but not imported by the app code. Their intended use: Not Defined.

Scripts (`package.json`): `dev`, `server`, `start`, `lint`, `typecheck`, `check`, `contracts:build`, `contracts:test`, `deploy:self`, `compass:deploy`, `fetch:abi`. There is **no** `build` script; build with `bunx vite build`.
